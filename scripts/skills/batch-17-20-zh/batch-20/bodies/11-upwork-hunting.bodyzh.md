# Upwork 猎单 — 发现、投标、拿下自动化工作

系统化地在 Upwork 上寻找并赢得工作，以我们 2,061 个 n8n 工作流模板库作为速度优势。
所有输出保存至 `workspace/artifacts/`。

## 适用场景
- 扫描 Upwork 寻找可投标工作
- 为 n8n/自动化/AI 智能体工作撰写提案
- 评估某份工作是否值得花费 connect
- 利用模板库估算交付时间
- 相对其他自由职业者定位自身优势

## 不适用场景
- 撰写实际提案文案（使用 proposal-writing 技能）
- 投标后处理客户异议（使用 objection-handling 技能）
- 中标后做发现（使用 client-discovery 技能）
- 我们领域外的工作（平面设计、文案、移动开发）

## 反例
- 「帮我构建 n8n 工作流」→ 否。本技能用于**寻找**工作，不是执行工作。
- 「帮我写作品集案例」→ 否。不同任务。
- 「我该提高费率吗？」→ 否。使用 pricing-psychology 技能。

## 边界情况
- 固定价 vs 时薪评估 → 是。本技能涵盖两者。
- 「这工作是不是骗局？」→ 是。含危险信号检测。
- 需要 n8n + 自定义代码的工作 → 是。评估模板 + 轻量代码是否可行。

## 工作定向标准

### 理想工作画像（积极投标）
- **类别：** n8n 自动化、工作流自动化、API 集成、AI 聊天机器人
- **预算：** $200-2,000 固定价 或 $30-75/小时
- **发布：** <48 小时
- **提案数：** <15
- **客户：** 已验证付款、消费 $1K+、评分 4.5+
- **范围：** 交付物定义清晰
- **模板匹配：** 库中已有 70%+ 工作流

### 良好工作画像（选择性投标）
- **预算：** $100-200（小但可快速拿评价）
- **发布：** 2-5 天前且提案 <20
- **范围：** 略模糊但在我们领域内
- **客户：** Upwork 新用户但已验证付款

### 避免（别浪费 Connect）
- 预算低于 $50（不值得时间）
- 已有 50+ 提案（竞争过烈）
- 「帮我做个 App」预算 $100（期望不现实）
- 未验证付款
- 范围模糊且无预算区间
- 「找长期合作，现在低薪以后会涨」（通常不会）

## 提案公式（精简版）

完整版使用 proposal-writing 技能。Upwork 快速格式：

```
第 1 行：提及他们的具体需求（证明你读过）
第 2 行：「我做过 [类似项目] — [结果]」
第 3 行：「我会用 n8n [方法]，在 [时间] 内交付 [成果]」
第 4 行：「乐意先做 [小里程碑] 供您评估」
第 5 行：关于他们需求的问题（邀请回复）
```

**可强调的差异点：**
- 「我有在线 n8n 实例，24 小时内可演示您的工作流」
- 「我维护 2,000+ 已测试工作流模板库」
- 「自动化运行在**您的**基础设施上 — 无月费 SaaS」
- 「含文档，您的团队可自行维护」

## Connect 花费策略

起始预算：100 connects（$15 投入）

**分配：**
- 60% 投第一档工作（胜率高、交付快、积累评价）
- 30% 投第二档工作（收入更高、中等投入）
- 10% 投第三档工作（搏大奖，中了回报高）

**目标：** 前 2 周赢得 2-3 份工作。初期重 5 星评价而非收入。

**何时补充 connects：**
- 胜率 >15%（好 — 继续投）
- 胜率 <10%（暂停 — 先改进提案）

## 工作评估记分卡

花费 connect 前为工作打分：

| 因素 | 1-5 分 | 权重 |
|--------|-----------|--------|
| 预算与范围是否匹配 | | 25% |
| 模板覆盖度（预建比例） | | 25% |
| 客户质量（评分、历史、验证） | | 20% |
| 竞争度（<15 提案） | | 15% |
| 后续潜力（续费/增购） | | 15% |

**投标门槛：** 加权分 3.5+
**自动跳过：** 任一因素得 1 分

## 前 30 天 playbook

**第 1 周：** 投 8-10 个第一档工作。目标：赢 2 个，快速交付，拿 5 星评价。
**第 2 周：** 投 5-8 个第一档+第二档混合。目标：再赢 2 个，建立档案可信度。
**第 3 周：** 时薪从 $49 提到 $59。开始只投第二档。
**第 4 周：** 瞄准 1-2 个第三档工作（$500+）。档案已有 4+ 评价。

**收入目标：** 前 30 天 $800-1,200。加上 Alfred（$149/月），合计 $950-1,350/月 — 逼近 $2K 目标。
