# 内容创意（免费版）

再也不愁没东西可写。本技能根据你的细分领域生成内容创意。

## 快速开始

```
「给我 10 个关于 [你的细分/行业] 的博客选题」
```

```
「围绕 [主题] 做一周社媒内容」
```

## 功能

- **博客选题** — 带切入角度的文章标题
- **社媒话题** — 有互动潜力的帖子创意
- **内容主题** — 月度/季度主题
- **热点角度** — 时效性内容机会

## 输出示例

```
自由职业网页设计师的 10 个博客选题：

1. 「5 个信号说明你的网站正在流失客户」
2. 「2024 年网站该花多少钱？」
3. 「DIY vs 专业：何时该请网页设计师」
4. 「3 页就能转化的网站」
5. 「为什么漂亮的网站却卖不动」
6. 「移动优先设计：对你的生意意味着什么」
7. 「如何为网页设计师准备内容」
8. 「廉价网页设计的隐性成本」
9. 「网站改版：何时以及为何」
10. 「案例：我们如何帮 [客户] 线索翻倍」
```
