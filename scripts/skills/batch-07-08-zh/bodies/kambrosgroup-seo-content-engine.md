# SEO 内容引擎

创作能在搜索中排名的内容。本技能引导你完成完整 SEO 内容工作流 — 从关键词研究到发布草稿 — 每一步都基于数据决策。

## 功能

- **关键词研究**：发现低竞争、高意图关键词
- **SERP 分析**：理解 Google 对目标词的要求
- **内容大纲**：构建满足搜索意图的文章结构
- **SEO 优化草稿**：正确的标题层级、内链与 meta 标签
- **内容刷新**：更新旧文以恢复排名

## SEO 内容工作流

### 阶段 1：关键词情报

**输入**：种子主题或竞品 URL  
**输出**：带难度评分的优先级关键词列表

关键指标：
- **搜索量**：月搜索次数（高 ≠ 总是更好）
- **关键词难度**：竞争程度（新站建议从 <30 开始）
- **搜索意图**：信息型、导航型、交易型、商业型
- **CPC**：每次点击成本（反映商业价值）

### 阶段 2：SERP 分析

写作前分析前 10 名结果：

1. **内容类型**：博客？产品页？清单？指南？
2. **内容深度**：字数、覆盖章节、细节程度
3. **内容缺口**：缺什么你可以补充？
4. **共性元素**：前几名是否都有视频、表格、FAQ？
5. **域名权威**：对手是 Wikipedia 还是小型博客？

### 阶段 3：大纲创建

SEO 友好结构：

```
H1: 目标关键词（精确或近似变体）
  H2: 引言（钩子 + 承诺 + 证明）
  H2: 什么是 [主题]？（信息意图的定义）
  H2: 为什么 [主题] 重要（收益、数据）
  H2: [数量] 最佳 [选项]（清单/对比类）
    H3: 选项 1
    H3: 选项 2
    H3: 选项 3
  H2: 如何 [达成结果]（教程章节）
  H2: 常见错误
  H2: FAQ（覆盖「People Also Ask」）
  H2: 结论 + CTA
```

### 阶段 4：草稿撰写

**页面 SEO 清单**：
- [ ] 前 100 词含关键词
- [ ] 至少一个 H2 含关键词
- [ ] URL slug 含关键词
- [ ] meta title 含关键词（前置）
- [ ] meta description 含关键词
- [ ] 内链（每 1000 词 3–5 条）
- [ ] 外链至权威来源
- [ ] 图片 alt 含关键词
- [ ] 长文配目录
- [ ] Schema 标记建议

**内容质量清单**：
- [ ] 原创洞见或数据
- [ ] 可执行建议（非纯理论）
- [ ] 建议视觉元素（图、表、图表）
- [ ] 短段落（最多 2–3 句）
- [ ] 要点列表便于扫读
- [ ] 案例与实例
- [ ] 统计数据更新（2 年内）

## 内容刷新策略

### 何时刷新

- 排名下跌 5 位以上
- 内容超过 2 年
- 竞品发布更好内容
- 有新信息/产品
- 流量逐月下降

### 刷新清单

1. **更新数据与案例**（当年）
2. **扩充薄弱章节**（竞品超越处加深）
3. **提升可读性**（更短段落、更好排版）
4. **新增章节**（趋势、新工具、新方法）
5. **优化新关键词**（相关词、长尾变体）
6. **刷新 meta**（更好标题/描述提升 CTR）
7. **增加内链**（链向站内新内容）
8. **更新发布日期**（标为「已更新」）

## 模板

### Meta Title 公式

- 「[数量] 种在 [时间] 内 [达成结果] 的方法」
- 「[关键词]：[受众] 完全指南（[年份]）」
- 「如何 [期望结果]（即使 [常见障碍]）」
- 「[受众] 最佳 [产品/服务]（[年份] 更新）」
- 「[关键词] vs [竞品]：哪个更适合 [场景]？」

### Meta Description 公式

- 「发现 [数量] 种经过验证的 [收益] 方法。本指南涵盖 [主题]，助你 [结果]。」
- 「在找 [解决方案]？我们对比前 [数量] 个 [选项] 帮你选择。」
- 「用分步指南学习如何 [达成结果]。含 [功能/福利]。」

## 常见错误

1. **关键词堆砌** — 自然语言永远胜出
2. **忽视搜索意图** — 排第 1 但意图不对 = 无转化
3. **忽略内链** — 最易做的 SEO 增益，多数人跳过
4. **忘记移动端** — 60%+ 搜索来自手机
5. **不做内容推广** — 好内容不推广 = 无人问津
6. **发布即忘** — 内容需持续更新才保持相关
