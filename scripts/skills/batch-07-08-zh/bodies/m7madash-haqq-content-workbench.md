# Haqq 内容工作台

## 概述
基于用户参考文本生成准确、可讨论的内容，避免重复与薄弱引用。

## 工作流（按需选用）

### 1）长文摘要
- 提取 5–10 个要点。
- 保留作者原意；不添加新主张。
- 输出：**摘要 + 3 条关键收获**。

### 2）来源/主张核查
- 列出需要出处的主张。
- 无法核实时标注：**「needs source」**。
- 绝不编造引用。

### 3）创建帖子变体（防重复）
- 产出 3 个结构不同的变体：
  1) **钩子 + 2 个短段 + 提问**
  2) **要点列表 + 结尾提问**
  3) **短故事/类比 + 教训 + 提问**
- 每个变体控制在 120–160 词以内。

### 4）生成讨论题
- 提供 5–8 个问题。
- 混合：反思型、批判型与实践型。

### 5）归档待发布创意
- 以紧凑格式存储：**标题 / 角度 / 草稿 / 问题 / 标签**。

## 参考文本
`references/al-amr-al-mutlaq.md` — 完整参考文本（绝对命令），用于引用、摘要或出题。

## 模板与模式
使用 `references/templates.md` 中的模板以保持输出一致。
