# 技能：Nexus-Orchestrator (V1.1)

面向 AI 的系统诊断与恢复智能 SRE 桥接器。

## 🛡️ 安全与隐私协议
- **日志脱敏**：编排器内置脱敏引擎，在将日志发送至推理服务前遮蔽密码、令牌与邮箱。
- **通用二进制支持**：不再依赖 root 家目录路径，会在系统 PATH 或用户本地目录中查找 `opencode`。
- **隐私提示**：本技能会将脱敏后的日志片段发送至你配置的 AI 推理服务（如 OpenCode/Codex）。请确保 AI 提供商符合你的数据政策。

## 📋 能力
- **推理优先恢复**：阻止盲目重启。分析日志以区分代码缺陷（告警用户）与基础设施故障（重启服务）。
- **日志情境化**：自动获取并脱敏与故障相关的日志供 AI 分析。

## ⚙️ 逻辑与保障
- **人工监督**：若在 OpenClaw 中配置，关键操作仍需 `/approve`。
- **诊断步骤**：智能体必须先通过 `bridge.py` 完成分析，再执行任何恢复操作。

## 🚀 安装
1. `pip install psutil`
2. 确保已安装 `docker`、`pm2` 与 `opencode`。
