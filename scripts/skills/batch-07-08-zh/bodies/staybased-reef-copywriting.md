# 文案写作 — 高转化销售文案

使用经过验证的直接响应框架撰写落地页、产品描述、广告与销售文案。
来源：Digitaloft（13 种框架）、CrazyEgg、NON.agency、DesignRush（直接响应案例）。
所有输出保存至 `workspace/artifacts/`。

## 何时使用
- 撰写落地页文案（Gumroad、产品页、ClawHub 列表）
- 撰写能转化访客的产品描述
- 撰写广告文案（社交、搜索、展示）
- 优化转化率低的现有文案
- 撰写 Upwork 简介或服务列表
- 撰写 CTA 按钮与微文案
- 销售页区块（首屏、功能、证言、定价）

## 何时不用
- 冷启动外展邮件（用 cold-outreach — 格式不同）
- 为 SEO 写的博客（目标不同 — 流量而非即时转化）
- 技术文档（清晰 > 说服）
- 提案（用 proposal-writing）

## 反例
- 「帮我写冷邮件」→ 不行。用 cold-outreach。
- 「帮我改简历」→ 不行。格式完全不同。
- 「写技术 README」→ 不行。是文档，不是销售。

## 边界情况
- Upwork 个人简介 → 可以。它是迷你销售页 — 你在推销自己。
- ClawHub 技能描述 → 可以。描述应促使人安装。
- 邮件主题行 → 可以。主题行是转化文案（打开率 = 转化）。
- Discord 频道描述 → 边界。仅当需要驱动行动时。

## 六大核心框架

按文案目标选择框架：

### 1. PAS — 问题、激化、解决
**最适合：** 落地页、产品页、痛点驱动产品。

```
[问题] 每次电话进语音信箱，你都在流失预约。
[激化] 每周 3–5 个客户 — 每月 $300–500 从指缝溜走，而你的双手正忙。
[解决] 我们的短信自动化接住每个未接来电并自动预约。一位理疗师 30 天内从每周 15 位客户增至 22 位。
```

**何时用：** 受众已知有问题。激化让他们感受不作为的代价。

### 2. AIDA — 注意、兴趣、欲望、行动
**最适合：** 广告、邮件主题、通用销售页。

```
[注意] 如果你的智能体能在你睡觉时赚钱呢？
[兴趣] The Reef 编排本地 AI 模型 24/7 处理任务 — 无云 API 费用。
[欲望] 想象打开仪表盘，看到一夜完成 50 项任务，计算成本 $0。
[行动] 以 $29 获取 The Reef → [CTA 按钮]
```

**何时用：** 需要抓住冷流量并引导至行动。

### 3. FAB — 特性、优势、利益
**最适合：** 产品描述、功能页、对比区块。

```
[特性] 自动短信回复
[优势] 5 秒内回复未接来电 — 比任何人都快
[利益] 再也不会因语音信箱流失预约。客户忙碌时仍感到被重视。
```

**何时用：** 需要把功能翻译成用户在乎的理由。多数科技产品只描述功能，忘记利益。

### 4. BAB — 之前、之后、桥梁
**最适合：** 转型导向文案、案例、证言。

```
[之前] 你在疗程间隙手动查语音信箱，几小时后才回短信。
[之后] 手机全自动 — 即时回复、自动预约、每次疗程后发送评价请求。
[桥梁] 我们的自动化系统连接手机与日历。设置约 15 分钟。
```

### 5. 4P — 承诺、画面、证明、推动
**最适合：** 长销售页。

```
[承诺] 无需雇前台即可翻倍预约。
[画面] 想象结束一次疗程，看到 3 个新预约已确认 — 全在你工作时搞定。
[证明] 「第一个月我从每周 15 位增至 22 位。」— Alfred，Soothing Escape Massage
[推动] 今天开始免费试用。随时取消。→ [CTA]
```

### 6. 明星-故事-方案
**最适合：** 关于页、品牌叙事、个人销售。

```
[明星] 认识 Celeste — 住在 Mac mini 上、为小企业构建自动化的 AI 智能体。
[故事] 由厌倦小企业主淹没在行政事务中的独立开发者打造。
[方案] 如今 Celeste 驱动短信自动化、预约系统与 AI 工作流 — 起价 $149/月。
```

## 落地页结构

高转化落地页按此顺序：

### 1. 首屏
- **标题：** 一个清晰承诺（10 词以内）
- **副标题：** 如何兑现承诺（1–2 句）
- **CTA：** 主行动按钮
- **视觉：** 产品截图、演示或相关图

**公式：** 「[结果] 无需 [痛点]」
- 「自动化预约，不错过任何客户」
- 「运行本地 AI 模型，无需云 API 账单」

### 2. 问题区块
用 PAS。点出痛点。要具体。

### 3. 方案区块
用 FAB。展示你做了什么，以及对他们为何重要。

### 4. 社会证明
- 带具体结果的证言（「从 X 到 Y」）
- 客户 logo（若 B2B）
- 数字（「500+ 智能体使用此技能」）
- 星级或评价摘录

### 5. 如何运作
3 个简单步骤。降低复杂度。
```
步骤 1：[简单首步]
步骤 2：[我们完成工作]
步骤 3：[他们获得结果]
```

### 6. 定价
使用 pricing-psychology 技能。先展示价值再标价。高价锚定。

### 7. FAQ / 异议处理
以问答形式回应前 4–5 个异议（见 objection-handling）。

### 8. 最终 CTA
重复首屏 CTA。若有真实紧迫感可加入。

## 文案规则（不可妥协）

1. **为扫读者而写。** 多数人 skim。用标题、要点、加粗、短段。
2. **一句一义。** 复杂句扼杀转化。
3. **「你」>「我们」。** 文案关于他们，不是你。数「你」与「我们」的比例。
4. **具体 > 模糊。** 「每周省 5 小时」胜过「省时间」。数字建立信任。
5. **利益 > 特性。** 特性说明。利益销售。始终翻译。
6. **CTA = 动作动词 + 结果。** 「Get Started」< 「今天开始自动化」
7. **删减 30%。** 初稿总是太长。无情删减。每词都要有价值。
8. **大声朗读。** 若磕绊就重写。文案应像对话般流畅。

## 平台注意事项

**Gumroad 列表：**
- 标题 = 利益驱动标题（非仅产品名）
- 搜索中仅前 2 行可见 — 要抓人
- 用要点列功能/利益
- 含「内含什么」区块

**ClawHub 技能描述：**
- 开头写技能解决什么问题
- 「何时用 / 何时不用」浏览者可见 — 要有说服力
- 含结果：「X 个智能体使用」或「源自 Y 个来源」

**Upwork 简介：**
- 前 2 行 = 钩子（「更多」前可见）
- 以 клиент结果开头，非简历
- 具体数字：「构建 50+ 自动化」> 「资深开发者」

## 核心原则
- 文案是对话，不是讲座
- 每段文案只有一个任务：让他们采取**下一步**
- 标题承担 80% 工作 — 花 50% 时间在标题上
- 具体建立信任。模糊滋生怀疑。
- 测试 > 意见。有疑问就 A/B 测试。
